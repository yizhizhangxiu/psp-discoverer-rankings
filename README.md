# PSP 发现者统计排行

本仓库用于发布和保存 **PSP 发现者统计排行** 网页。项目以静态 HTML 页面形式呈现统计列表，便于访问、查阅与归档相关排行信息。

## 内容说明

| 文件 | 说明 |
|---|---|
| `PSP发现者统计排行.html` | PSP 发现者统计排行的网页文件。 |

## 更新机制

> **列表信息将每隔一个月（即每两个月）进行一次人工核对与手动更新。**

本项目不采用自动抓取或自动发布机制。维护者将在每次更新周期内，根据当时可核实的信息整理并更新列表内容；更新完成后将通过 Git 提交记录保留变更历史，供读者查阅。

## 使用方式

可直接在浏览器中打开 `PSP发现者统计排行.html` 查看排行页面。若需获取最新版本，请以本仓库 `main` 分支中的文件为准。

## 维护说明

本仓库为信息展示与历史版本留存用途。列表数据可能在两次计划更新之间发生变化，因此请结合页面最近一次提交时间判断信息时效性。
